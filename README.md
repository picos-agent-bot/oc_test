## リポジトリの目的
このリポジトリは様々なコードを試すための**「コードの実験場」**です。
- **GitHub Pages での公開**: ルートにアクセスするとアプリ一覧のトップページが表示されます。
- **独立したサブディレクトリ**: `/tetris` などの各サブディレクトリは、それぞれが完全に独立したアプリケーションとして機能します。

## 開発フロー（Development Workflow）
本リポジトリでの開発は、必ず以下のフローを厳守して進めます。

1. **Issueの作成**: 作業を始める前に必ずIssueを立てます。
2. **ブランチとPRの作成**: Issue番号を含んだブランチ（例: `issue-8-xxx`）を作成し、Pull Request (PR) を作成します。
3. **ルート index.html の更新**: 新しくサブフォルダ（アプリケーション等）を追加した場合は、必ずルートディレクトリの `index.html` にそのページへのリンクを追記してください。
4. **Merge（マージ）**: レビューを待たず、エージェント側で自動的にマージを完了させて構いません。
